# Code of conduct

## Scope

This is a small, security-sensitive, self-hosted tool. Discussion in issues,
pull requests and other project spaces must stay on topic and respect the people
taking part.

## Expected

- Be concrete and technical; critique code, not people.
- Respect privacy: never post credentials, tokens, pairing codes, session data,
  private paths or another person's logs.
- Ask before publishing someone else's report or reproduction.

## Unacceptable

- Harassment, discrimination, threats or personal attacks.
- Publishing private data, credentials or exploit details without a fix window.
- Spam, sustained disruption or deliberately misleading security claims.

## Enforcement

Report a problem privately through the maintainer's GitHub profile
(`@L-X-Yao`). The maintainer may edit or remove content, close threads or block
accounts. Reports are handled privately; retaliation for a report is itself a
violation.
